## なぜ「タイヤハウス」のデッドニングが効果的なのか？

車の騒音の大きな原因の一つが「ロードノイズ」です。ロードノイズは、タイヤと路面が擦れ合う摩擦によって発生します。

発生した騒音は、まず鉄板や樹脂のインナーライナーで構成される**「タイヤハウス（フェンダー内部）」**を激しく振動させます。そこから車体のフレームを通じて、直接あなたの耳へ「ゴー」という低周波の騒音となって伝わっているのです。

つまり、タイヤハウスの防音施工は**「騒音の発生源のすぐそばで音を叩き潰す」**という、極めて効率的なアプローチになります。

### 施工による騒音レベル（dB）の測定検証データ

実際に施工前と施工後の高速道路での騒音レベルをデシベル計で測定しました（車種：コンパクトミニバン）。

| 測定ポイント | 施工前 | 施工後 | 静音効果 |
| :--- | :--- | :--- | :--- |
| 一般舗装路（50km/h） | 64.2 dB | 59.8 dB | **-4.4 dB** |
| 荒れたアスファルト（60km/h） | 67.8 dB | 62.1 dB | **-5.7 dB** |
| 高速道路（80km/h） | 71.5 dB | 65.3 dB | **-6.2 dB** |

一般的に、騒音が **3 dB 低下すると「音のエネルギーが半分」**になり、人間の耳には「明らかに静かになった」とハッキリ体感できます。
**-6 dB 前後の低減効果は、まるで「ワンクラス上の高級乗用車」に乗っているかのような圧倒的な変化**です。

## 具体的な施工プロセス

当店の出張タイヤハウスデッドニングでは、以下のプロフェッショナル基準で施工を行います。

1. **インナーライナーの取り外し＆徹底清掃**
   タイヤハウス内の樹脂ライナーを丁寧に取り外し、泥や油分を徹底的に除去して脱脂を行います。

2. **高比重ブチル制振材の圧着施工**
   ライナーの裏側、およびフェンダー金属部に超制振シート「レアルシルト」等を丁寧に熱圧着し、鉄板の不快な共振を完全にシャットアウトします。

3. **独立気泡防音・吸音シートの追加施工**
   制振材の上に、さらに水や泥に強い撥水高密度スポンジシートを重ね貼りし、高周波のロードノイズを吸収・遮断します。

4. **ライナーの復元**
   干渉やクリアランスを綿密に計算し、クリップやビスを全て新品、または綺麗に清掃した状態で完璧に元通りに組み上げます。
