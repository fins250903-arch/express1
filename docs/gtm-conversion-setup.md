# Google広告 × GTM コンバージョン計測 設定手順

対象LP: `https://abura.site/deadning/`（実体は `/deadning/osaka/` などの地域ページ。`/deadning/` は地域ページへ即リダイレクトします）
GTMコンテナ: `GTM-5Z6MXK8W`
計測したいCV: ①電話問い合わせ（`tel:070-8428-0866`）／②LINE問い合わせ（`https://lin.ee/g4NPYZ3`）

> このリポジトリ側では、**GTMコンテナのタグをLPに埋め込む作業（`src/layouts/Layout.astro`）は完了済み**です。
> LPの全ページ（`<Layout>` を使う全ページ）の `<head>` と `<body>` に `GTM-5Z6MXK8W` が出力されます。
> あなたが手動で行うのは、以下の **Google広告の管理画面** と **GTMの管理画面** での設定だけです。

---

## 0. 全体像（何をやるか）

1. Google広告で「電話」「LINE」の **コンバージョンアクションを2つ作成** し、それぞれの **コンバージョンID / ラベル** を取得する。
2. GTMで、その2つのCVを送信する **タグ** と、いつ発火させるかの **トリガー** を作成する。
3. GTMの **プレビューモード** で、ボタンを押したときに正しくタグが発火するかテストする。
4. 問題なければGTMを **「公開」** する。
5. Google広告の管理画面で、広告グループ毎に **CV数・CV率の列を表示** する。

---

## 1. Google広告で「広告グループ毎のCV数・CV率」を表示する

CVはアカウント共通で計測し、表示だけを広告グループ単位に切り替えます。

1. Google広告にログイン → 左メニュー **「キャンペーン」** を開く。
2. 上部の階層メニューで **「広告グループ」** タブをクリック（キャンペーン一覧ではなく広告グループ一覧を表示）。
3. 表の右上にある **列アイコン（縦棒が並んだアイコン）→「列の変更」** をクリック。
4. **「コンバージョン」** カテゴリを開き、以下にチェックを入れる:
   - `コンバージョン`（＝CV数）
   - `コンバージョン率`（＝CV率）
   - （任意）`コンバージョン値` `費用 / コンバージョン単価`
5. 右下の **「適用」** をクリック。広告グループ一覧に列が追加されます。
6. （任意）**「列を保存」** で「CV分析」などの名前を付けておくと、次回ワンクリックで同じ表示に戻せます。
7. 特定のCVだけを見たい場合は、上部 **「セグメント」→「コンバージョン」→「コンバージョンアクション」** を追加すると、行が「電話」「LINE」に分かれて表示されます。

> ポイント: 「CV率 = CV数 ÷ クリック数」です。広告グループ毎の数値は、上記の列設定を広告グループ階層で行うだけで自動集計されます。

## 2. コンバージョンID・コンバージョンラベルの確認／再取得

GTMの設定に必須の2つの値です。**アクションごとに「ラベル」は異なり、「ID」はアカウント共通**です。

1. Google広告 右上の **「ツールと設定」（レンチアイコン）→「測定」→「コンバージョン」** を開く。
2. コンバージョンアクションの一覧が出る。**まだ無ければ新規作成**:
   1. **「＋ 新しいコンバージョンアクション」→「ウェブサイト」** を選択。
   2. 手動設定（Googleタグを使う方法）を選ぶ。
   3. 1つ目: 目標カテゴリ「**電話 → ウェブサイトのボタンクリックによる電話**」または「お問い合わせ」、名前を **「電話問い合わせ」** とする。
   4. 2つ目: 同様に「**お問い合わせ / 見込み顧客**」で、名前を **「LINE問い合わせ」** とする。
   5. 計測方法は後でGTMから送るので、値・カウント方法（電話は「1回」、LINEも「1回」推奨）を設定して保存。
3. 一覧から対象アクション名（例:「電話問い合わせ」）をクリック → **「タグ設定」→「タグを手動でインストールする」** を開く。
4. 表示されるコードの中に以下があります。ここが確認・再取得ポイント:
   - `AW-XXXXXXXXX` … これが **コンバージョンID**（`AW-` から始まる。アカウント共通）
   - `'send_to': 'AW-XXXXXXXXX/YYYYYYYYYYYYYYY'` の **スラッシュ以降 `YYYY...`** が **コンバージョンラベル**（アクション毎に固有）
5. 「電話問い合わせ」「LINE問い合わせ」の **2アクション分のID・ラベルをメモ**します（IDは共通、ラベルは2種類）。

| アクション | コンバージョンID | コンバージョンラベル |
|---|---|---|
| 電話問い合わせ | AW-XXXXXXXXX | （ここに控える） |
| LINE問い合わせ | AW-XXXXXXXXX | （ここに控える） |

## 3. 対象LPへのタグ埋め込み（このリポジトリで対応済み）

`src/layouts/Layout.astro` に `GTM-5Z6MXK8W` のスニペットを埋め込み済みです。

- `<head>` の先頭付近: `gtm.js` を読み込むスクリプト（`is:inline` で最適化を回避して原文どおり出力）
- `<body>` の直後: JavaScript無効時用の `<noscript>` iframe

このLPは `/deadning/[地域]/` の各ページ、`/[エリア]/[キーワード]/` の各ページなど、`<Layout>` を通す全ページで自動的にGTMが読み込まれます。**追加のコード作業は不要**です。デプロイ後、実サイトの `<head>` に `GTM-5Z6MXK8W` が入っていることを確認してください。

> 注意: 各CTAボタンは既に `<a href="tel:070-8428-0866">` / `<a href="https://lin.ee/g4NPYZ3">` のリンクになっているため、GTMの「クリックURL」トリガーでそのまま検知できます。ボタン側の改修は不要です。

## 4. GTMでの「電話問い合わせ」「LINE問い合わせ」設定手順

### 4-1. 組み込み変数を有効化（最初に1回だけ）

1. GTM（`GTM-5Z6MXK8W`）を開く → 左メニュー **「変数」**。
2. 「組み込み変数」右上の **「設定」** をクリック。
3. **クリック系** をすべて有効化（特に **`Click URL`**、`Click Element`、`Click Text` にチェック）。

### 4-2. コンバージョンリンカーtag（必須・最初に1回だけ）

Google広告のCVを正しく計測するために必要です。

1. 左メニュー **「タグ」→「新規」**。
2. タグ名: `コンバージョンリンカー`。
3. **「タグの設定」→ タグタイプ「コンバージョンリンカー」** を選択。
4. **「トリガー」→「All Pages（全ページビュー）」** を選択。
5. 保存。

### 4-3. トリガーを作成（電話・LINEの2つ）

**電話クリック用トリガー**
1. 左メニュー **「トリガー」→「新規」**。名前: `クリック - 電話`。
2. トリガータイプ: **「クリック - リンクのみ」**。
3. 「このトリガーの発生場所」: **「一部のリンククリック」** を選択。
4. 条件: **`Click URL` / 含む / `tel:`**。
5. （推奨）「タグの配信を待つ」にチェックし、待ち時間 `2000` ミリ秒。「妥当性をチェック」はオフでOK。
6. 保存。

**LINEクリック用トリガー**
1. 同様に「新規」。名前: `クリック - LINE`。
2. タイプ: **「クリック - リンクのみ」**、**「一部のリンククリック」**。
3. 条件: **`Click URL` / 含む / `lin.ee`**。
4. 保存。

> 補足: LINEボタンは `target="_blank"`（別タブ）で開きます。別タブ遷移でもクリックイベント自体は発火するため計測できます。電話（`tel:`）はページ遷移が発生しないため確実に発火します。

### 4-4. コンバージョンタグを作成（電話・LINEの2つ）

**電話コンバージョンタグ**
1. **「タグ」→「新規」**。名前: `CV - 電話問い合わせ`。
2. タグタイプ: **「Google 広告のコンバージョン トラッキング」**。
3. **コンバージョンID**: セクション2で控えた `AW-XXXXXXXXX`。
4. **コンバージョンラベル**: 電話アクションのラベル `YYYY...`。
5. トリガー: **`クリック - 電話`** を紐付け。
6. 保存。

**LINEコンバージョンタグ**
1. 同様に「新規」。名前: `CV - LINE問い合わせ`。
2. タグタイプ: **「Google 広告のコンバージョン トラッキング」**。
3. コンバージョンID: `AW-XXXXXXXXX`（共通）。
4. コンバージョンラベル: LINEアクションのラベル。
5. トリガー: **`クリック - LINE`** を紐付け。
6. 保存。

> まとめ: タグは3つ（コンバージョンリンカー×1 + Google広告CV×2）、トリガーは2つ（電話・LINE）になります。

## 5. プレビューモードで動作テスト

1. GTM右上の **「プレビュー」** をクリック → Tag Assistant が開く。
2. 「Your website's URL」に **`https://abura.site/deadning/osaka/`**（公開前に確認するなら実サイトURL。ローカルで確認する場合は開発URL）を入力し **「Connect」**。
3. 新しいタブでLPが開き、GTMと接続された状態になる（Tag Assistant に「Connected」と表示）。
4. LP上で **電話ボタン** を1回クリック（実際に発信しないよう、テスト機ならキャンセルでOK）。
5. Tag Assistant 画面に戻り、左の **イベント列に `Link Click`** が追加されていることを確認 → それを選択 → **「Tags Fired」に `CV - 電話問い合わせ` が入っていればOK**。
6. 同様に **LINEボタン** をクリック → `Link Click` イベントで **`CV - LINE問い合わせ` が Fired** になっていることを確認。
7. 各タグをクリックすると、`Conversion ID` `Conversion Label` が正しい値になっているか確認できます。
8. うまく発火しない場合のチェック:
   - `Click URL` 変数が有効か（4-1）。
   - トリガー条件の文字列（`tel:` / `lin.ee`）が合っているか。
   - トリガータイプが「リンクのみ」かつ「一部のリンククリック」になっているか。
9. 問題なければ Tag Assistant を閉じ、GTMで右上 **「公開」→ バージョン名を付けて「公開」**。

### 公開後の最終確認
- 公開から数時間〜24時間後、Google広告「ツールと設定 → コンバージョン」で対象アクションのステータスが **「未確認」→「計測中」** に変わります。
- テストクリックが本番CVに混ざるのを避けたい場合は、公開直後の自分のテストは避けるか、後で件数を差し引いて考えてください。

## よくある質問

- **Q: `/deadning/` はリダイレクトされるが計測できる?**
  A: `/deadning/` は即座に `/deadning/osaka/` 等へ転送され、転送先ページでGTMが読み込まれるため、そこでのボタンクリックが計測されます。広告のリンク先（最終ページURL）は実際にユーザーが滞在する地域ページを指定してください。
- **Q: 電話番号のタップ以外（番号を目で見てかける）は計測できる?**
  A: GTMのクリック計測は「電話リンクのタップ」を計測します。PCで番号を見て別の電話でかけた場合は計測対象外です（これは仕様上の限界で、一般的にモバイルのタップ発信が主対象です）。
